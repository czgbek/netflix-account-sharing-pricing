## 常见问题

**合租会被封号吗？**
有概率。Netflix 用同户装置验证和登录地检测来识别跨户共享，2026 年以来风控明显收紧，这也是多家平台账号频繁失效的直接原因。合租车位用的是平台持有的账号，你无法控制它的登录环境，被封后能做的就是找平台换号。

**年付比月付划算吗？**
单价上月付确实更贵。以 4K奈飞为例，月付 16.8、年付 229.9，年付折合每月 19.2，反而更高，因为月付那一档是短期促销价。真正的问题不在折扣，而在你愿不愿意把 200 到 380 元押在一个可能停运的平台身上，蜜糖商店和奈飞小镇的用户已经替这个问题交过学费。

**合租和官方额外成员差在哪？**
额外成员是你自己主账户下的一个子账号，有独立邮箱密码，费用交给 Netflix，主账户随时能停；合租是别人账号下的一个车位，钱交给平台，账号所有权、续费和退款都不在你手上。前者贵，后者便宜，区别就在这。

**台湾、香港、美区价格差多少？**
按高级方案看，台湾 NT$460、香港 HK$118、美区 $26.99，币种不同不换算，但香港的名义数字最低。官方价格按地区独立设定，跨区订阅还要面对付款方式和地区验证的问题。
